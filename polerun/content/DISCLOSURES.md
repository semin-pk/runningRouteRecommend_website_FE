### 2-4. 가입 인증·비밀번호 복구 메일: Google Gmail SMTP

운영·테스트의 인증·비밀번호 복구 메일은 Google Gmail SMTP(`smtp.gmail.com`, TLS587)로 발송하며 발신 주소는 help.polerunapp@gmail.com, 발신 이름은 PoleRun입니다. Google LLC 및 실제 제공에 관여하는 계열사·처리자가 수신 이메일, 제목·본문, 인증/복구 링크 등 발송에 필요한 정보를 처리합니다. 이용자가 가입 인증·재발송·비밀번호 복구를 요청할 때 Supabase Auth에서 Google 메일 시스템으로 전송합니다. 인증메일 발송본은 발송일부터30일 보관 후 운영자가 메일함·휴지통에서 삭제합니다. 문의 메일의 처리 완료 후6개월 기준과 구분합니다.

Google의 처리 국가·내부 삭제·백업은 위2-3의 안내를 따르며, 국외 처리에 필요한 상세 국가·관계·근거 확인은 아직 완료되지 않았습니다. 운영 SMTP의 실제 발송·받은편지함 수신은 확인했지만 이 사실만으로 국외 처리 공시나 모든 앱 인증 흐름을 완료 처리하지 않습니다.

### 2-5. 선택한 소셜 로그인

운영 서비스에는 Apple·카카오·Google 로그인이 활성화되어 있으며 사용자가 세 공급자의 로그인 동작을 확인했습니다. 이용자가 선택한 제공자의 계정 식별자·제공에 동의한 이메일/프로필과 인증 결과를 처리합니다. Apple의 이메일 가리기 등 공급자가 실제 제공한 범위를 따릅니다. 전체 주행 원본이나 원본 진단을 로그인 항목으로 공급하지 않습니다. 제공자별 실제 항목·계약상 역할·국가·기간·연결 해제의 최종 대조는 남아 있으며, 로그인 성공을 이 검증의 완료로 보지 않습니다.

### 2-6. GPX 길 검증·갈림길·지역명 조회

현재 GPX 길 검증은 PoleRun 서버에서 Supabase Storage의 자체 OSM 보행로 데이터셋을 읽어 수행합니다. 등록 경로·주변 영역을 Private.coffee 조회 서버로 직접 보내는 기존 처리와 구분합니다. 파일에서 추출한 경로와 검사 결과는 코스 등록·검토 목적으로 PoleRun 서버에 처리됩니다.

앱의 갈림길 조회에는 공개 코스 주변 영역을 `overpass-api.de`로 보내는 별도 요청이 있습니다. 코드상 러너의 현재 주행 원본을 해당 요청 본문에 넣는 구조와는 구분하지만, IP·접속정보·공개 코스 영역의 실제 처리 관계·보관·국가 확인은 필요합니다. 지역명 확인에는 출발점 좌표를 OS 역지오코딩에 전달합니다. OS 공급자의 외부 처리 범위도 별도 확인 대상입니다.

### 2-7. 공개 웹페이지와 코스 링크

공개 소개·정책·문의·코스 공유 페이지는 AWS Amplify에서 제공합니다. 승인된 공개 코스의 경로·설명을 Supabase 공개 API로 가져와 표시하며, 비로그인 방문자도 볼 수 있습니다. 계정 인증정보·개인 주행 원본·표본 시각·비공개 코스·원본 진단은 이 공개 응답에 넣지 않습니다.

기존 `chatgpt.site` 주소는 새 공식 페이지로 이동시키는 안내 역할을 유지합니다. AWS 및 기존 호스팅 공급자의 접속 IP·요청 로그 등 처리 범위·국가·기간과 필요한 계약/고지를 실제 서비스 사용 범위에 맞춰 대조해야 합니다. 정적 페이지가 GPS를 직접 기록하지 않는다는 이유로 웹 접속정보의 처리가 없다고 설명하지 않습니다.

## 3. 국외 처리 안내와 이용자의 선택

확정된 국외 처리마다 이전받는 자와 연락처, 항목, 목적, 국가, 시점·방법, 보유·이용 기간, 적용 법적 근거 및 거부 방법·영향을 알립니다. 동의가 필요한 경우에는 해당 내용을 구분하여 동의를 받습니다. 공급자 방침의 링크만으로 필요한 내용을 모두 알렸다고 간주하지 않습니다.

이용자는 앱의 관련 설정 또는 help.polerunapp@gmail.com을 통해 처리 중지·동의 철회·삭제를 요청할 수 있습니다. 계정·DB·지도 등 필수 처리의 제한으로 관련 기능을 제공할 수 없으면 그 영향을 구체적으로 안내합니다. 문의 메일을 선택하지 않았다는 이유로 앱 내 계정 삭제를 제한하지 않습니다.
